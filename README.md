# GRIY · Finanzas 360

Simulador competitivo de administración financiera para clase.

## Funciones
- Un mismo enlace reutilizable.
- Administrador crea una sala nueva con código GRIY-XXXX y PIN.
- Hasta 30 participantes por defecto.
- 5 rondas con eventos comunes para todos.
- Decisiones sobre operación, CAPEX, controles, deuda y financiamiento.
- Ranking, métricas grupales y ganador final.
- Base de datos compartida en Supabase.

## Despliegue
1. Entra a https://share.streamlit.io e inicia sesión con GitHub.
2. Crea una app desde el repositorio `GabrielPV24/GRIY-FINANZAS-360`.
3. Branch: `main`.
4. Main file path: `app.py`.
5. Elige un subdominio disponible, por ejemplo `griy-finanzas-360`.
6. Pulsa Deploy.

El enlace de Streamlit se conserva para futuras partidas. Para volver a usarlo, abre la misma app y crea una sala nueva.

## Nota didáctica
Los porcentajes de mitigación y los efectos de eventos son supuestos del juego para fines académicos; no son estimaciones empíricas reales.
